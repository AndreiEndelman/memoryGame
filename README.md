# Project 4 - *Memory Game*

Submitted by: **Andrei Endelman**

**Memory Game** is a SwiftUI app where players flip cards to find matching pairs. The app tracks moves, hides matched cards, and supports resetting or changing the number of pairs.

Time spent: **X** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] Users see a grid of cards initially placed face-down.
- [x] Users can tap cards to toggle their display between the back and the face.
- [x] Tapping a second non-matching card flips both cards back down.
- [x] When two matching cards are found, they disappear from view.
- [x] User can reset the game and start a new game via a button.
 
The following **optional** features are implemented:

- [x] User can select number of pairs to play with (2, 4, 6, 8).
- [x] App allows user to scroll to see pairs out of view.
- [x] UI flavor added with gradients, card styling, and animations.

The following **additional** features are implemented:

- [x] Move counter and match progress display.
